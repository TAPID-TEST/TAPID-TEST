TapID final student-experience update

1. Run tapid-final-student-experience.sql in the Supabase SQL Editor.
2. Upload these updated site files to the root of the GitHub repository:
   - index.html
   - login.html
   - employer-login.html
   - university-login.html
   - dashboard.html
   - profile.html
   - styles.css
3. Commit the files and wait for GitHub Pages to finish deploying.
4. Hard refresh tapidcard.com (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac).

What changed:
- New focused landing message and student-profile preview; no NFC language.
- Student login now continues the same visual story.
- Public profile photo is beside the student's identity and no longer overlaps actions.
- Resume has its own professional-document section and disappears when unavailable.
- Open-to-opportunities colors have stronger contrast.
- Students can write a short opportunity statement in their own words.
- Student home emphasizes incomplete profile work and relevant relationship activity.
