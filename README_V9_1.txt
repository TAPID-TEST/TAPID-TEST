TapID V9.1 — Flow and Usability Remodel

Install order
1. Run tapid_v9_1_flow_and_outcome_fix.sql in Supabase.
2. Upload all extracted website files to the GitHub repository root.
3. Commit to main and wait for Netlify to publish.

Highlights
- Polished public landing page with one Get Started route to role-based login.
- Student profile pause/reactivate control moved to Account & Privacy.
- Student Network overview now prioritizes connections, unread messages, and next actions.
- Employer sidebar regrouped around relationships, events, and company identity.
- Career fairs use Available, Awaiting Approval, and Approved/Active stages.
- Candidate workspace adds priority, follow-up date, notes, messaging, pipeline stage, and activity history.
- One current employer-verified outcome per employer connection prevents duplicate milestones.
- Expanded company profile with careers URL, company size, culture, and student-facing message.
- Student message conversations can resolve actual employer names.
