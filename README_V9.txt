TapID V9 — Share Center and Connected Messaging

Install order
1. Run tapid_v9_share_and_messaging.sql in the correct Supabase project.
2. Upload every extracted website file to the GitHub repository root.
3. Commit to main and wait for Netlify to publish.

What changed
- Public-profile preview opens as the normal interactive TapID again.
- PDF-preview and Save PDF behavior were removed.
- Students have a Preview & Share center with copy-link, native sharing,
  public preview, and direct access to QR/NFC controls.
- Students and verified employers can exchange private messages only after
  an employer connection exists.
- Employer messages create student in-app notifications.
- Existing career-fair search, favorites, profile readiness, private outcomes,
  recommendations, and role-based login remain intact.
