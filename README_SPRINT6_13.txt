TapID Sprint 6.13 — Career Fair Connection Requests

Student:
- Career Fairs section lists only companies registered through recruiter current-event settings.
- Company names are shown; recruiter contact details are not exposed.
- One request per student/company/event.
- Request requires a short message.
- Pending/declined requests are not connections.
- Accepted requests automatically become mutual connections.

Employer:
- New Connection Requests inbox.
- Employer sees the student's public TapID identity and message before accepting.
- Accept creates the normal employer candidate connection and gives the student the accepting recruiter's contact information.
- Decline does not expose recruiter information.

Run sprint6_13_connection_requests_patch.sql before deployment.
